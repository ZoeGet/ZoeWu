智能枕头 V1.1 调试问题与解决方法

芯片与关键型号

  • WT2605 音频芯片：WT2605C8-32N，厂家：深圳唯创知音电子有限公司（WT）。串口固件版本：WTQ240126-12-L011V1.0。
  • MCU：CH32V003A4M6，厂家：南京沁恒微电子（WCH）。
  • Flash：WT25Q32X-8S，32 Mbit，唯创配套器件。
  • 功放：TPA2012D2RTJR，厂家：Texas Instruments。
  • 关键连接：PA1=PINCH/ADC1，PA2=PRESS/ADC0，PC6=AMP_EN，CH32 PD5/PD6 与 WT2605 UART 相连，115200 8N1。

1. PA1 按压后没有播放声音

问题： 蓝牙播放正常，但按下 PA1 后只有功放切换产生的“咚”声，没有本地 MP3。

2. PA1 压力判定方向或阈值错误

问题： 薄膜压力传感器压力越大阻值越小，软件容易把电压方向或 ADC 位数判断错。

解决办法： 实测 PA1 未按压约 3.3 V，按压后降至接近 0 V，所以 ADC 值降低表示按下。CH32V003 是 10 位 ADC，满量程约 1023，当前使用：

3. 上电或按压没有 1 kHz 蜂鸣

问题： 发送 AT+1KTONEON 没有声音，串口返回 ERR。

解决办法： 本板未连接 WT2605 PWM 输出，且当前 WT2605 固件不接受该命令。1 kHz 蜂鸣不作为本板测试项目，改用 AT+CHMODE=4 和 AT+SPLAY 验证本地音频。

4. SD 卡和 Flash 查询都是 NULL

问题： 更换 4 GB FAT32 卡、检查上拉和供电后，AT+GETALLDEV? 仍显示存储设备离线。

解决办法： 静态电压确认无误后检查 WT2605、SD 卡座和 Flash 的逐线连通及焊点。最终根因是虚焊，补焊后存储恢复。已实测：WT2605 pin31 VOUT=3.3 V，SD VDD=3.3 V，CMD/DAT0 空闲=3.3 V。持续 NULL 时不能只继续换卡或加上拉。

问题： 仅听声音无法判断 WT2605 是否找到文件或执行了命令。

6. 蓝牙暂停但不能证明本地播放成功

问题： 按压时蓝牙音乐暂停，容易误以为 SPLAY 已成功。

解决办法： 蓝牙暂停只证明 PA1 触发及 CHMODE=4 执行。必须观察 WT2605 UART 是否返回：

没有返回时，检查 CH32 TX、WT2605 RX、115200 波特率、命令结尾 \r\n 和发送时序。

7. 没有示波器时如何定位问题

问题： 无法直接观察 UART 波形和音频波形。

解决办法： 使用万用表和串口分段确认：测 PA1 空闲/按压电压，测 PC6 播放期间是否保持有效，手工发送 AT 命令并记录完整返回。若已返回 +PLAY:START 仍无声，再换标准 44.1 kHz、128 kbps CBR MP3 或 PCM WAV。

当前状态

  • 存储识别失败的根因已确认是虚焊，补焊后 AT+SPLAY=sd0,0001.mp3 可返回播放开始。
  • PA1 的实测电压方向与低电平触发逻辑匹配。
  • 蓝牙音频链路正常。
  • 当前固件不设置音量，按压流程为 CHMODE=4 → 等待 1 秒 → SPLAY。
  • 烧录最新 HEX 后，应继续用 UART 返回确认 PA1 触发时的命令与手工命令完全一致。
