五、总结

遇到 ModuleNotFoundError: No module named 'intelhex' 时，可以按下面的顺序处理：

  1. 确认错误发生在生成 bootloader.bin 的阶段；
  2. 检查 .platformio\packages\tool-esptoolpy 目录是否完整；
  3. 使用 PlatformIO 自带 Python 执行 package-postinstall.py；
  4. 重新执行 pio run 验证编译结果。

这个问题一般不需要修改 ESP32 项目代码，也不需要重新安装整个 PlatformIO，只要补全 tool-esptoolpy 的依赖即可。
